# H21 · Onboarding „Zacznij tutaj"

**Priorytet:** P0 · **Rozmiar:** S · **Moduł:** M16

## Zakres

Pierwszy ekran ścieżki uczestnika (`/panel/start`): film-placeholder, przebieg
programu, oczekiwania. Treść trzech sekcji edytuje administracja bez kodu —
zmiana widoczna natychmiast. Ekran działa też po ukończeniu programu i po
wygaśnięciu dostępu.

## API

| Metoda | Trasa | Rola | Uwagi |
|---|---|---|---|
| `GET` | `/api/v1/onboarding` | każda zalogowana | bez `access.active` — działa po wygaśnięciu i po ukończeniu programu |
| `PATCH` | `/api/v1/admin/onboarding` | `super_admin`, `project_manager` | częściowa aktualizacja sekcji; walidacja przez FormRequest |

Kształt odpowiedzi (`{ "data": ... }`):

```json
{ "data": {
  "video": { "title": "...", "url": null, "caption": "..." },
  "program": { "title": "...", "body": "..." },
  "expectations": { "title": "...", "body": "..." },
  "updated_at": null
} }
```

Bez audytu — rejestr §3.2 kontraktu nie przewiduje sluga dla onboardingu.

## Przechowywanie

Jeden wiersz w tabeli `settings` (klucz `onboarding`, `value` = JSON). Brak
migracji. Brak wiersza => `GET` zwraca `OnboardingContent::DEFAULTS`, więc ekran
działa na czystej bazie. Seed demo zakłada wiersz z treścią domyślną.
